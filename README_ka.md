# საშინაო დავალება 9 — Command Code-ის დაყენება

მოგესალმებით მეცხრე საშინაო დავალებაზე! 🎉

მე-10 workshop-ზე უყურეთ, როგორ იპოვა და გაასწორა **Command Code**-მა, ანუ AI აგენტმა, Supra-ს გვერდზე ხუთი ბაგი, თქვენ კი ყოველ diff-ზე წინასწარ ვარაუდობდით, ეძებდით და ხმას აძლევდით. ეს დავალება ამ ხელსაწყოს **თქვენს** კომპიუტერზე გადმოიტანს. დააყენებთ მას, მისცემთ თქვენს საკუთარ წესებს და მისი დახმარებით სამ ბაგს იპოვით. მთელი დროის განმავლობაში შემმოწმებელი თქვენ რჩებით.

სულ **სამი სავარჯიშოა** და თითოეულს ერთი ფაილი მოაქვს:

| | ფაილი | რას აკეთებთ |
|---|---|---|
| 1 | `setup.md` | აყენებთ Node 22+-ს და Command Code-ს, შედიხართ ანგარიშზე და ამტკიცებთ, რომ მუშაობს |
| 2 | `AGENTS.md` | `/init`-ით Command Code-ს თქვენს საკუთარ წესებს აძლევთ |
| 3 | `exercise_3.js` | plan mode → სამი ბაგის პოვნა → გასწორება სათითაოდ → ყოველი შესწორების ახსნა საკუთარი სიტყვებით |

## სანამ დაიწყებთ

### 💳 ეს $1 ღირს

Command Code-ს **უფასო გეგმა არ აქვს**. ყველაზე იაფი გეგმა, **Go**, **თვეში $1** ღირს, პლუს მცირე საკომისიო, და მასთან ერთად $10-ის კრედიტს იღებთ. ეს ბევრად მეტია, ვიდრე ამ დავალებას სჭირდება. ეს გამოწერაა: ყოველ თვე განახლდება, სანამ არ გააუქმებთ.

> **ვერ იხდით, ან ბარათი არ გაქვთ?** მომწერეთ **ვადის გასვლამდე** და სხვა გზას ვიპოვით. უბრალოდ ნუ გამოტოვებთ დავალებას.

### 🪟 `cmdc` თუ `cmd`?

| თქვენი კომპიუტერი | ბრძანება |
|---|---|
| Windows | `cmdc` |
| macOS, Linux | `cmd` |

Windows-ზე სახელი `cmd` უკვე დაკავებულია ძველი Windows-ის ტერმინალით, ამიტომ Command Code იქ `cmdc`-ს იყენებს. ყველგან, სადაც ამ დავალებაში `cmdc` წერია, Mac-ისა და Linux-ის მომხმარებლები `cmd`-ს წერენ.

### 🧑‍⚖️ შემმოწმებელი თქვენ ხართ

workshop-ის ხუთი წესი ყველა სავარჯიშოზე ვრცელდება:

1. **ჯერ გეგმა.** ერთ ხაზზე დიდი ნებისმიერი ცვლილება plan mode-ით დაიწყეთ.
2. **ერთ ჯერზე ერთი ცვლილება.** პატარა diff არის ის diff, რომლის წაკითხვაც რეალურად შეგიძლიათ.
3. **წაიკითხეთ ყოველი diff, სანამ მიიღებთ.**
4. **თავად გაუშვით.** "გასწორდა" მხოლოდ მტკიცებაა; დასტური შედეგია.
5. **ვერ ხსნით ხაზს? ნუ დატოვებთ.** სთხოვეთ, აგიხსნათ, ან ამოაგდეთ ეს ხაზი.

და კიდევ ერთი: **არასოდეს ჩასვათ პაროლები, ტოკენები ან API გასაღებები** Command Code-ში ან `AGENTS.md`-ში.
